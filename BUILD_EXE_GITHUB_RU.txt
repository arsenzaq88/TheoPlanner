КАК ПОЛУЧИТЬ ГОТОВЫЙ TheoPlanner.exe ЧЕРЕЗ GITHUB
=================================================

В этом архиве есть автоматическая сборка для Windows. GitHub соберёт EXE на своём Windows-компьютере, поэтому Windows не нужна на твоём текущем компьютере для самой сборки.

1. Открой https://github.com и создай бесплатный аккаунт или войди в него.
2. Нажми + вверху справа -> New repository.
3. Назови репозиторий TheoPlanner, выбери Public или Private, затем Create repository.
4. В созданном репозитории нажми Add file -> Upload files.
5. Распакуй архив TheoPlanner_Windows.zip на компьютере. ВАЖНО: загрузи СОДЕРЖИМОЕ папки TheoPlanner, а не сам ZIP.
6. Перетащи все файлы и папку .github в окно загрузки GitHub. Если папка .github не показывается в проводнике, включи показ скрытых элементов или загрузи файл .github/workflows/build-windows.yml отдельно, сохранив именно этот путь в репозитории.
7. Нажми Commit changes.
8. Открой вкладку Actions в репозитории. Выбери workflow “Build TheoPlanner for Windows”. Если сборка не стартовала автоматически, нажми Run workflow.
9. Дождись зелёной галочки у сборки, открой её страницу и найди раздел Artifacts внизу.
10. Скачай артефакт TheoPlanner-Windows-EXE.zip и распакуй его. Внутри будет TheoPlanner.exe.
11. Запусти TheoPlanner.exe двойным нажатием. При первом запуске Windows может показать предупреждение о неизвестном издателе, потому что приложение не подписано цифровым сертификатом.

ПРИМЕЧАНИЕ
- GitHub Actions собирает EXE; он не публикует приложение как сайт.
- Данные программы сохраняются локально в %APPDATA%\TheoPlanner\data.json.
- Не загружай в публичный репозиторий личные данные или реальные списки участников. Для личного использования лучше выбрать Private.
- Если сборка завершится ошибкой, пришли скриншот вкладки Actions с текстом ошибки — я помогу исправить.
