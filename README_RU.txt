TheoPlanner — настольный прототип для Windows
============================================

Это отдельная программа с графическим окном, не сайт. Данные сохраняются локально в:
%APPDATA%\TheoPlanner\data.json

Что работает в этой версии:
- расписание встреч: добавление, изменение, удаление;
- список участников;
- задания с именами участников;
- импорт EPUB: извлечение и просмотр текста рабочей тетради;
- экспорт расписания и заданий в CSV, который открывается в Excel;
- локальное сохранение данных.

Важно про форматы:
- EPUB поддерживается для извлечения текста. Автоматическое распознавание дат и разнесение частей по неделям пока не реализовано.
- PUB пока не поддерживается как полноценный импорт. В TheocBase импорт расписания обычно работает с workbook EPUB. Поддержка PUB зависит от точного типа файла.

Запуск из исходников:
1. Установи Python 3.11 или новее с python.org.
2. При установке отметь Add Python to PATH.
3. Дважды нажми run_windows.bat.

Создание EXE на Windows:
1. Открой папку программы на Windows.
2. Запусти build_exe.bat.
3. После завершения готовый EXE будет в dist\TheoPlanner.exe.

Это первая рабочая основа, а не полная замена TheocBase: пока нет полноценного парсера рабочей тетради, шаблонов печати PDF, территорий, синхронизации и автоматической проверки конфликтов. Следующий этап — проверить импорт на твоём EPUB-файле и расширить расписание по реальному содержимому.
